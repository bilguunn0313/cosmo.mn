# Cosmo вэбсайтын дизайны дүрэм

Нийтийн сайтын (`src/components/site`, `src/app/(site)`) бүх шинэ ажил энэ дүрмийг дагана. Админ панел shadcn-ийн өөрийн загвартай тул хамаарахгүй.

## Энэ баримтыг хэрхэн өөрчлөх вэ

Энэ бол амьд баримт. Аль нэг хэсэгт шинэ загвар хүсвэл (жишээ нь өөр сайтын скриншот):
1. Хүсэлт энэ дүрэмтэй зөрчилдөх эсэхийг эхлээд шалгана.
2. Зөрчилдвөл юутай зөрчилдөж байгааг хэлээд, хоёр сонголт өгнө: дүрмийг дагасан хувилбар эсвэл дүрмийг өөрчлөх.
3. Шинэ загвар батлагдмагц **энэ баримтад дүрэм болгон нэмнэ**. Ингэснээр бусад хуудас ч түүнийг дагана.

## Чиглэл

**Логоноос эхэлсэн, итгэлтэй, цэвэрхэн, найрсаг корпорацийн сайт.**

Логоны үсгүүд бөөрөнхий, геометр хэлбэртэй. Навчин тэмдэг нь зөөлөн, амьд мэдрэмжтэй. Тиймээс сайт ч мөн хурц, хатуу биш, **зөөлөн булантай, нэг гүн хөх өнгөтэй** байна. Чимэглэл бага, зураг болон агуулга гол үүрэгтэй.

**Сайт зөвхөн танилцуулах зориулалттай.** Вэбээр захиалга, үнийн санал авахгүй. «Үнийн санал авах», «Бөөнөөр захиалах», «Сагсанд нэмэх», үнэ зэрэг худалдааны товч, мэдээлэл хаана ч тавихгүй. Брэнд, бүтээгдэхүүний хуудас зөвхөн мэдээлэл харуулна. Холбогдох хүсэлтэй хүн «Холбоо барих» хуудсаар дамжина.

## Өнгө

Эх сурвалж нь брэндийн албан ёсны гарын авлага (`CosmoTrade BrandGuideline26.pdf`, 2026). Лого, өнгө, фонтын асуудлаар энэ баримт гарын авлагатай зөрчилдвөл **гарын авлага давамгайлна**.

Палитр: Deep Blue `#1B4D7F`, Soft Ivory `#F9FCF0`, Dusty Blue `#84ABCE`, Muted Gold `#FBC877`, Terracotta `#E9624C`. Гарын авлагын 60-30-10 дүрэм: 60% ivory суурь, 30% гүн хөх, 10% тодотгох өнгө. Вэбсайтад суурь нь цагаан (доор тайлбарласан).

Сайт голдуу **хөх болон саарал** өнгөтэй. Шүрэн болон шаргал нь зөвхөн маш цөөн тодотголд (жишээ нь «Шинэ» шошго, газрын зургийн цэг) хэрэглэгдэнэ. Товч, гарчиг, дэвсгэрт хэрэглэхгүй.

|---|---|---|

| `brand-600` | `#17426C` | Товчны hover |

| `brand-300` | `#B5CDE2` | Бараан дэвсгэр дээрх eyebrow |
| `brand-200` | `#D6E3EF` | Идэвхтэй/сонгогдсон дэвсгэр |
| `brand-100` | `#EBF1F7` | Hover дэвсгэр, картын цайвар дэвсгэр |

Гарын авлага өөрөө цагаан хуудсан дээр хийгдсэн, цагаан нь логонд зөвшөөрөгдсөн дэвсгэр. Саарал хуудасны дэвсгэр ч бүдэг, «бохир цагаан» мэт харагддаг тул хэрэглэхгүй. Бараан хэсэг (`brand-night`) хуудас бүрт **хамгийн ихдээ нэг** удаа, footer-ээс гадна.
- Hex утгыг компонентод шууд бичихгүй, зөвхөн токен ашиглана.

## Булан (radius)

| Юу | Булан |
|---|---|
| Карт, зураг, панел, ангиллын карт | `rounded-card` (20px) |
| Товч, input, select, шүүлтүүр, жижиг шошго | `rounded-control` (10px) |
| Жижиг зураг (лого хайрцаг, thumbnail) | 12px |
| Бүтэн өргөнтэй баннер, бараан хэсэг, header, footer | 0, дэлгэцийн ирмэгт наалдана |

Хурц (0px) булантай карт, товч цаашид хэрэглэхгүй.

## Хүрээ, тусгаарлалт

- **Картыг шугамаар биш, дэвсгэрээр** ялгана (`bg-surface` эсвэл `bg-paper`). Картын эргэн тойронд border тавихгүй.
- Цагаан дэвсгэртэй зураг (бүтээгдэхүүн, брэндийн лого) саарал карт эсвэл өнгөт тууз дээр цагаан дөрвөлжин болж харагдахгүйн тулд `mix-blend-multiply` хэрэглэнэ.
- Мэдээний зургийн дотор талд `ink`-ийн 8%-тай 1px сүүдэр (`NewsCover`) байна. Энэ нь border биш: цайвар дэвсгэр дээр цайвар зургийн ирмэг уусахгүй байлгана.
- Шугам (`border-rule`, 1px) зөвхөн жагсаалтын мөр, хүснэгт, footer-ийн доод мөрөнд хэрэглэнэ.
- Section-уудыг шугамаар биш, **зай болон дэвсгэрийн өнгөөр** тусгаарлана.

## Үсэг

- Фонт (брэндийн гарын авлага): гарчиг, тоо, eyebrow нь **IBM Plex Sans** (`font-display`). Үндсэн текст, товч, цэс нь **Roboto** (`font-sans`). Хоёулаа кирилл Ө Ү бүрэн. Хятадад Noto Sans SC.
- `type-*` utility болон h1–h4 элемент IBM Plex Sans-ийг автоматаар авна. Гарчиг биш элементэд гарчгийн фонт хэрэгтэй бол `font-display` нэмнэ.
- Гарчгийн үсгийн зай `-0.02em`-ээс илүү шахахгүй. IBM Plex Sans өөрөө нягт фонт.
- Хэмжээ (`globals.css`). Шинэ хэмжээ зохиохгүй, эдгээрээс сонгоно. **Хуудасны гарчиг үргэлж хамгийн том.**

| Токен | Компьютер / гар утас | Хэрэглээ |
|---|---|---|
| `type-hero` | 72 / 40px | Баннертай хуудасны h1 (нүүр, Бидний тухай, Брэндүүд), брэндийн нэр |
| `type-section` | 52 / 32px | Eyebrow-той section бүрийн гарчиг (нүүрний газрын зураг орно), баннергүй хуудасны h1 (Медиа, мэдээ, Холбоо барих) |
| `type-display` | 40 / 32px | Бүтээгдэхүүний нэр. Медиа тайзны мэдээний гарчиг `type-h2 lg:type-display` (h1-ээс үргэлж жижиг) |
| `type-h2` | 36 / 28px | Дэд хэсгийн гарчиг («Бусад брэнд», «Хүсэлт илгээх») |
| `type-h3` | 28 / 22px | Зураг дээрх картын гарчиг («Бидний хийдэг зүйл»), Facebook тууз |
| `type-h4` | 22 / 18px | Карт, жагсаалтын гарчиг (мэдээ, брэнд, «Яагаад Космо Трейд», түүх, үйл явц), эрхэм зорилго / алсын хараа |
| `type-stat` | 48 / 36px | Зөвхөн тоо |
- Гарчиг, картын гарчигт `text-[..px]` бичихгүй, токеноос сонгоно. Токены жинг `font-semibold`-оор, мөрийн өндрийг `leading-tight`-аар өөрчилж болно. Зөвхөн чимэглэлийн тоо, ишлэл (захирлын ишлэл, «30%», 404) токенгүй байж болно.
- `eyebrow` (жижиг том үсгэн шошго) хуудас бүрт **3 section тутамд хамгийн ихдээ 1**.
- Дугаарласан шошго (01, 02…) хэрэглэхгүй.

## Зай

- Section хоорондын зай: `pt-20 md:pt-32` (өнгөт дэвсгэртэй хэсэгт `mt-20 md:mt-32`). Өөр утга (28, 36, 40) хэрэглэхгүй.

## Icon

- Тоон үзүүлэлт гэх мэт **брэндийн дүрслэлийн icon**: гарын авлагын өөрийн icon багц (`Brand icon set.ai`), `components/site/brand-icons.tsx` (хөх `fill-brand` + terracotta `fill-coral`, хоёр өнгөтэй). Шинэ icon хэрэгтэй бол AI файлаас ижил аргаар нэмнэ.
- Бусад UI icon (сум, chevron, цэс, хаах, дуу): **lucide-react**. Өөр сан холихгүй.
- Сошиал сүлжээний лого (Facebook, Instagram, YouTube): **simple-icons**-ийн албан ёсны дүрс, `components/site/social-icon.tsx`. Footer-т `size-10` `rounded-control` `bg-white/10` товч дотор 20px, цагаанаар. Гараар SVG зурахгүй. simple-icons-д байхгүй брэнд (LinkedIn) текст холбоосоор үлдэнэ.
- Зураасны зузаан: дүрслэлийн icon (картан дээрх, тоон үзүүлэлтийн, мэдээллийн мөрийн) **`strokeWidth={1.5}`**. Сум, chevron зэрэг жижиг UI icon анхдагч утгаараа (2).
- Хэмжээ: 20px (мөр доторх), 24px (жагсаалт), 48px (карт).
- Icon-д дэвсгэр хэрэгтэй бол: `rounded-control` + цайвар дэвсгэр (`bg-brand-100`, бараан дээр `bg-white/10`). Хүрээтэй icon хайрцаг хэрэглэхгүй.

## Нүүр хуудасны hero carousel

- `components/site/home/hero-carousel.tsx`. Header-ийн **доор**, бүтэн өргөнтэй. Өндөр нь `HERO_HEIGHT_CLASS` (`hero-size.ts`): 360 / 432 (sm) / 480 (xl) / 584px (1440px+). Слайдгүй үеийн `HeroFallback` ч ижил өндөртэй.
- Слайд нь зөвхөн зураг эсвэл видео (+ видеоны poster). Гарчиг, тайлбар, «Бидний тухай» товч бүх слайд дээр ижил, текст файлаас (`home.hero*`) ирнэ. Админд слайдын гарчиг, холбоос байхгүй.
- Слайд 4 секунд тутамд хажуу тийш гулсаж солигдоно (600ms, `cubic-bezier(0.32, 0.72, 0, 1)`). Төгсгөлгүй давтагдана: сүүлийнхээс эхнийх рүү буцаж гүйхгүй.
- Хулгана, хуруугаар чирж солино. 50px-ээс их чирэх эсвэл хурдан шидэхэд солигдоно, бага бол буцаж байрандаа орно. Чирж байх үед autoplay зогсоно.
- Зүүн, баруун сум: хүрээгүй, `bg-brand-night/25` бөөрөнхий дэвсгэр, blur. Цайвар зураг дээр ч харагдана.
- Indicator: зурагны доод төвд жижиг дугуй цэгүүд (12px, 1.5px цагаан хүрээ, идэвхтэй нь цагаанаар дүүрнэ, бага зэрэг сүүдэртэй). Autoplay нь timer-ээр (`SLIDE_DURATION_MS`), чирж байх эсвэл гулсаж байх үед зогсоно.
- Зурган дээр зөвхөн сум, цэгүүд, видеоны дууны товч.

## Нүүр хуудасны «Бидний хийдэг зүйл»

- `components/site/home/business-areas-section.tsx`. `bg-brand` тууз, голдоо eyebrow + `type-section` гарчиг, доор нь зурагтай картууд (зураг дээр доороос бараан градиент, `type-h3` гарчиг, 1–2 өгүүлбэр текст).
- Картуудыг админ → Нүүр хуудас → «Бидний хийдэг зүйл»-ээс удирдана (`Section`, `page: "home"`, зураг заавал). Админд карт байхгүй үед `lib/business-areas.ts`-ийн анхны 5 карт (`public/images/home/area-*.webp` + `home.areas.items` текст) харагдана. Админд «Анхны 5 картыг хуулах» товч тэдгээрийг засаж болохоор хуулна.
- Хэлбэр картын тооноос хамаарна, хоосон нүд үлдэхгүй: компьютер дээр 3-аар мөр (өндөр 380px), үлдэгдэл 2 бол сүүлийн мөр 2, үлдэгдэл 1 бол сүүлийн 4 нь 2+2 (өндөр 320px); 1 карт бүтэн өргөн. Таблетад 2 багана, сондгой тоотой үед сүүлийнх бүтэн өргөн.

## Нүүр хуудасны тоон үзүүлэлт

- `components/site/home/key-stats.tsx`. Hero-гийн шууд доор бүтэн өргөнтэй **цайвар хөх тууз** (`bg-brand-100`, Dusty Blue-гийн цайвар өнгө), өндөр нь ойролцоогоор 160px. Картгүй.
- 4 зүйл нэг мөрөнд (утсан дээр 2×2). Зүүн талд гарын авлагын icon (жинхэнэ өнгөөрөө), баруун талд нь жижиг том үсэгтэй шошго (`ink-2`), доор нь гүн хөх тод тоо (28/22px, 0-ээс тоологдоно).
- Тоо нь админаас: Админ → Нүүр хуудас → Тоон үзүүлэлт (`SiteSetting.foundedYear`, `productCount`, `salesPointCount`, `employeeCount`). Байгуулагдсан оноос «33+ жил» гэж бодогдож, жил бүр өөрөө нэмэгдэнэ. Хоосон үзүүлэлт харагдахгүй. Шошго нь `home.keyStats`-д.
- Дарагддаггүй тул hover өнгө солихгүй.

## Нүүр хуудасны «Бидний тухай»

- `components/site/home/about-intro-section.tsx`. Тоон үзүүлэлтийн шууд доор, цагаан дэвсгэртэй.
- Компьютер дээр зүүн талд том зураг (5:4, `rounded-card`), баруун талд eyebrow, `type-h2` гарчиг, тайлбар, «Компанийн түүх» товч дээрээс доош. Утсан дээр текст эхэлж, зураг доор нь.
- Зураг дээр карт, текст давхарлахгүй. Уриатай хөх картыг туршаад хассан.
- Зураг: Админ → Нүүр хуудас → «Бидний тухай» хэсгийн зураг (`SiteSetting.homeAboutImage`). Байхгүй бол `HOME_ABOUT_IMAGE_PLACEHOLDER` (брэндийн гарын авлагын контейнерийн mockup).
- Хөдөлгөөн: зураг `ImageReveal`-ээр доороос нээгдэнэ, текст `Reveal`-ээр гарна.
- Нүүр хуудасны зүүн, баруун зураг+текст layout-ын «нэг удаа» эрхийг энэ хэсэг авна.

## Нүүр хуудасны «Брэндүүд» (Bento)

- `components/site/home/brand-bento.tsx`. Админ → Нүүр хуудас → «Онцлох брэндүүд»-д сонгосон 5 хүртэл брэнд (`Brand.featuredOrder`). Сонгоогүй бол брэндийн ерөнхий дарааллаар эхний 5. 1-рх нь том нүд, 2-рх нь өргөн, бусад нь жижиг. Брэнд цөөн бол нүдний хуваарь өөрчлөгдөж, хоосон нүд хэзээ ч үлдэхгүй (`LAYOUTS`).
- Нүд бүр брэндийн **нүүр зураг**, доороос `brand-night` градиент, цагаан нэр + ангилал, лого 10px бөөрөнхий цагаан хайрцагт. Hover дээр зураг 1.05, баруун дээд буланд сум.
- Нүүр зураггүй брэнд: `brand` → `brand-night` градиент, цагаан дугуйн дотор лого, бүдэг навчин тэмдэг.
- Брэнд бүрийг жагсаах ажлыг «Манай харилцагчид» тууз хийдэг тул энд шүүлтүүр, carousel хэрэглэхгүй.

## Брэндийн лого гүйдэг хэсэг

- Нүүр хуудсанд «Мэдээлэл»-ийн дээр. Тусдаа дэвсгэргүй энгийн section (`pt-20 md:pt-32`). Лого нь бүтэн өргөнөөр гүйнэ. Гарчиг нь `type-h2` («Манай харилцагчид», `home.partnersTitle`), доогуураа 3px градиент шугамтай (`brand` → `brand-400` → `rule`).
- Лого хүрээ, дэвсгэргүй, өнгөөрөө. 8 ба түүнээс олон брэндтэй үед 2 эгнээ эсрэг чиглэлд (эгнээ хооронд 60px), цөөн үед 1 эгнээ. Эгнээнд 6-аас цөөн брэнд байвал өргөн дэлгэцэнд зарим лого давтагдаж харагдана.
- Хэмнэл nanointernational.mn-тэй ижил: нүд бүр дэлгэцийн өргөний хэсэг (утас 1/2, 800px 1/3, 1024px 1/4, 1300px 1/5, 1900px 1/6), өндөр 96 / 150px. Лого нүдний голд 112×48 / 136×64px хайрцагт багтана. Хурд: 5 секундэд нэг нүд.
- Контейнер: `site-container` (90rem). Бүтэн өргөнтэй зүйлс (баннер, гүйдэг жагсаалт) л үүнээс гарна.

## Мэдээ

Бүх мэдээний карт **хайрцаггүй**: зураг өөрөө карт, текст шууд хуудасны дэвсгэр дээр.

| Компонент | Хаана | Хэлбэр |
|---|---|---|
| `NewsCard` | «Бусад мэдээ», нүүрний «Мэдээлэл» мөр | 16:10 зураг, огноо, `type-h4` гарчиг (3 мөр), 2 мөр хураангуй |
| `NewsSlide` | Медиа хуудасны тайз, нүүрэнд ганц мэдээтэй үед | Зураг 7 багана (4:3) + текст 5 багана: «2026 оны 11-р сар», том гарчиг, 4 мөр хураангуй, «Дэлгэрэнгүй →». Нүүрэнд `titleTag="h3"` |
| `NewsThumb` | Медиа хуудасны тууз | 220px (утсанд 160px) 16:10 зураг, сар, 2 мөр гарчиг |

**Нүүрний «Мэдээлэл»** хамгийн сүүлийн 3 мэдээг харуулна. Хоосон нүд үлдээхгүйн тулд хэлбэр нь мэдээний тооноос хамаарна: 1 мэдээ → `NewsSlide`, 2 → `md` дээрээс 2 багана, 3 → 3 багана. Мэдээгүй үед хэсэг харагдахгүй.

**Медиа хуудас: тайз ба тууз** (`NewsShowcase`). Мэдээ жилд хэдхэн удаа гардаг тул өдөр тутмын мэдээний сайтын тор, баннер, 10-аар хуудаслалт тохирохгүй.
- Хуудасны зам → `type-section` гарчиг + тайлбар (eyebrow-гүй, баннергүй) → тайз → тууз → Facebook хэсэг.
- Тайз нэг удаад нэг мэдээ (`NewsSlide`, бүхэлдээ холбоос). Бүх слайд DOM-д байна (бусад нь `invisible`), холбоосууд хайлтын системд харагдана.
- Тууз нь хэвтээ гүйдэг `aria-pressed` товчнууд. Дарахад тайз солигдоно: хуучин нь 100ms-д алга болж, шинэ нь 100ms хоцорч 250ms-д гарна (гарчиг давхцахгүй). Идэвхгүй зураг бүдэг (`opacity-75 saturate-60`), идэвхтэй нь 3px brand хүрээтэй. Ганц мэдээтэй үед тууз гарахгүй.
- Огноо зөвхөн он, сар (`NewsDate variant="month"`), өдрийг харуулахгүй: мэдээ ховор үед яг огноо сайтыг идэвхгүй мэт харагдуулдаг.
- Хуудаслалт 24-өөр: олон жил хэрэг болохгүй.
- Доор нь `FollowFacebookBand`: «Манай Facebook хуудсыг дагаарай» + Facebook товч. Админд Facebook холбоос оруулаагүй бол гарахгүй.

**Мэдээний дэлгэрэнгүй: нийтлэл** (`media/[slug]`).
- Хуудасны зам → голдоо 820px багана: «2026 оны 9-р сар · Видео», `type-section` гарчиг, хураангуй → 1120px медиа → 700px текст (`rich-text`, 17/18px, мөрийн өндөр 1.75) → «Өмнөх / Дараагийн мэдээ» → `FollowFacebookBand`. Хуваалцах товч тавихгүй.
- Медиа `rounded-card`, 16:9. Зурагтай мэдээнд `ImageReveal`-тай зураг.
- Видео (`NewsVideo`): нүүр зураг дээр 92px цагаан дугуй тоглуулах товч, зүүн доод буланд үргэлжлэх хугацаа (видеоны metadata-аас). Дарахад видео тоглож, хөтчийн өөрийн controls гарна. Видео 16:9-өөс нарийн бол хоёр талд нь нүүр зургийг бүдгэрүүлж тавина. Босоо видео утсан дээр 4:5 хүрээтэй.
- «Өмнөх / Дараагийн мэдээ» (`NewsPrevNext`) нь API-ийн `previous` (хуучин) ба `next` (шинэ) мэдээ. Өмнөх нь зүүн, дараагийн нь баруун талд байрлана. Ганцхан байвал өөрийн талдаа үлдэнэ. Мэдээ цөөн үед «Бусад мэдээ» тор шиг ганц картаар хоосон харагдахгүй.
- Сайтын `rich-text` доторх зураг `rounded-card` булантай.

- **Нүүр хуудасны «Мэдээлэл»** (`latest-news-section.tsx` + `news-rail.tsx`) нь чирэх мөр: сүүлийн 8 мэдээ `NewsCard`-аар хэвтээ гүйнэ.
  - Картын өргөн: гар утсанд 80%, `md` 45%, `lg`-ээс 340px. Мөр дэлгэцийн бүтэн өргөнөөр гүйнэ (`bleed-gutter`): эхний карт контейнерийн ирмэгтэй тэгш, дараагийн карт дэлгэцийн баруун ирмэг хүртэл цухуйна.
  - Мөр бүхэлдээ нэг `Reveal`-ээр гарна. Карт тус бүрд stagger хийхгүй: дэлгэцээс гадуурх карт гүйлгэж ирэхэд хоосон харагдах ёсгүй.
  - Хулганаар чирнэ, тавихад хамгийн ойр карт руу зөөлөн наалдана. Чирсний дараах click-ийг хүчингүй болгоно. Хүрэлтээр уугуул scroll + `snap-x`.
  - Гарчгийн мөрөнд 44px дугуй сум (`bg-paper`, hover `brand-100`) — зөвхөн `md`-ээс, мөр гүйх зүйлтэй үед. Төгсгөлд хүрэхэд тухайн сум бүдгэрнэ.
  - Мөрийн төгсгөлд «Бүх мэдээ» хавтан тавихгүй. «Бүх мэдээ →» холбоос зөвхөн гарчгийн мөрөнд.
- Огноо богино: «2026.10.20» (`NewsDate variant="short"`). Мэдээний дэлгэрэнгүй хуудсанд урт хэлбэрээр.
- «Мэдээ» шошго тавихгүй (хэсгийн гарчгийг давтдаг). Видео мэдээнд «Видео» шошго болон зургийн зүүн доод буланд 12px зайтай, `rounded-control` тоглуулах тэмдэг.
- Зураг бүр `NewsCover`-оор: саарал дэвсгэр дээр бүдэг гарч ирнэ (`FadeInImage`), hover дээр томорно, 1px дотор сүүдэртэй.

## Маягт (бүх хуудас)

- Сайтын бүх маягт (Холбоо барих, Ажлын байрны анкет) нэг хэв маягтай: `form-styles.ts`-ийн `inputClass` (доод зураастай талбар), `textareaClass` + `growTextarea` (нэг мөрөөр эхэлж доош сунана), `LineSelect` (доод зураас + сум), `formButtonClass` (хүрээтэй бөөрөнхий үндсэн товч). Заавал бөглөх талбарын шошгоны ард улаан « *» (`requiredMarkClass`), «заавал биш» гэж бичихгүй.
- Ажлын анкет `/human-resources/anket?job=<slug>`: зөвхөн нээлттэй, «Шийдвэр гарсан» биш ажлын байранд. `?job` байхгүй/хаагдсан бол «Энэ ажлын байранд анкет авахгүй байна» хоосон төлөв + «Нээлттэй ажлын байр» товч. Хуудас noindex, sitemap-д байхгүй.
- Бүтэц: хуудасны зам (Нүүр / Нээлттэй ажлын байр / {ажлын байр} / Ажлын анкет) → eyebrow «Ажлын анкет» + h1 = ажлын байрны нэр → 8/4 багана: зүүн талд маягт, баруун талд гүйлгэхэд дагах карт (анкет авах хугацаа, үлдсэн хоног, «* тэмдэгтэй талбарыг л заавал бөглөнө», «Анкетыг зөвхөн хүний нөөцийн алба үзнэ», утас). Утсан дээр карт гарчгийн доор.
- Маягт алхамгүй, нэг хуудас: `border-ink` шугамаар тусгаарласан дугааргүй хэсгүүд (Үндсэн мэдээлэл, Боловсрол, Ажлын туршлага, Ур чадвар) → нэг «Анкет илгээх» товч. Үндсэн мэдээлэлд зүүн талд 3:4 цээж зураг (`PhotoField`: аливаа зураг → хөтөч дээр JPEG ≤1MB), баруун талд Овог, Нэр, Нас, Хүйс (`RadioChips`, жинхэнэ radio). Ганц сонголт = дугуй тэмдэгтэй `RadioChips`, олон сонголт = сонгоход ✓ тэмдэгтэй `ChipGroup`. Жишээ placeholder бичихгүй (зөвхөн «Суралцаж байна», «Одоо» төлөв).
- Ноорог `sessionStorage`-д ажлын байраар хадгалагдана (зураг биш). Илгээх: `POST /api/public/jobs/:slug/apply` (multipart `data` JSON + `photo`), «Илгээж байна…», алдаа гарвал товчны доор `role=alert` мессеж (утастай). Амжилттай бол `bg-brand-100` самбар, гарчиг руу focus, «Бусад ажлын байр» товч. Анкет Resend-ээр SiteSetting.hrEmail (хоосон бол email) рүү зурагтай очно, өгөгдлийн санд хадгалагдахгүй.
- Ажлын анкет Хүний нөөц хуудсанд нээлттэй байрлахгүй (ggi.mn/hr шиг): тусдаа хуудас `/human-resources/anket` (`APPLICATION_PATH`). Анкет зөвхөн тодорхой ажлын байранд илгээгдэнэ, ерөнхий анкет авахгүй. Хүний нөөц хуудасны баннерын «Нээлттэй ажлын байр» товч ажлын байр байхад л харагдана. Хуудасны төгсгөлийн цайвар CTA ажлын байр байвал тоо + ажлын байрны товчнуудтай (`PartnerCtaSection` `children`) жагсаалт руу, байхгүй бол «Одоогоор алга» гэж хэлээд Facebook хуудас руу хөтөлнө.

## Нээлттэй ажлын байр

- canvas «Нээлттэй ажлын байр — жагсаалт» ба «Ажлын байрны дэлгэрэнгүй». Зураг хэрэглэхгүй (Хүний нөөц хуудсанд баннер бий), ggi.mn шиг хүснэгт.
- Жагсаалт `/human-resources/jobs`: хуудасны зам → `type-section` гарчиг → `JobsTable` (баганууд: Ажлын байр, Явц, Анкет авах хугацаа; толгой мөр `bg-brand-100` бөөрөнхий; мөр бүхэлдээ холбоос, сумгүй; огноо `tabular-nums`, «2026.11.30 хүртэл» + «19 хоног үлдсэн»). Явц нь 3 хэсэгтэй зураас + шатны нэр, хүснэгтийн доор тайлбар; зөвхөн мэдээлэл, анкет авах эсэхийг хугацаа шийднэ. 7 хоногоос бага үлдвэл `coral` цэг. Утсан дээр мөр бүр карт маягаар задарна. Ажлын байр байхгүй үед `bg-brand-100` хоосон төлөв: «Одоогоор нээлттэй ажлын байр алга», Facebook хуудас дагах товч, «Манай хамт олны тухай» холбоос.
- Дэлгэрэнгүй `/human-resources/jobs/[slug]`: хэлтэс (eyebrow) → нэр → 4 баримт (байршил, ажлын цаг, цалин, нийтэлсэн) шугамаар хуваасан мөр → 7/4 багана: зүүн талд товч танилцуулга, үүрэг / шаардлага / санал (`bg-brand` зураастай жагсаалт), баруун талд гүйлгэхэд дагах карт (хугацаа, үлдсэн хоног, «Анкет илгээх», холбоос хуулах). «Шийдвэр гарсан» шатанд анкет товч харагдахгүй. Утсан дээр карт гарчгийн доор шууд гарна. Доор нь бусад ажлын байр ижил хүснэгтээр.
- Огноо Улаанбаатарын цагаар (`toCompanyDate`); хаах огнооны өдрийн төгсгөлд жагсаалтаас автоматаар алга болно.
- Шошго талбарын дээр, `labelClass` (13px). Талбаруудын хоорондох босоо зай `gap-y-7`.
- Баннерын зураг хэрэглэхгүй. Google Хятадад нээгдэхгүй ч хаяг, холбоос газрын зургаас тусдаа үргэлж харагдана.

## Зураг

- Зорилго нь **компанийн өөрийн зураг**: агуулах, машин, хамт олон, бүтээгдэхүүн, брэндийн албан ёсны зураг. Админаас солигдоно.
- Зураг хараахан байхгүй бол текстээр орлуулахгүй, хоосон саарал дөрвөлжин ч үлдээхгүй. **Түр stock зураг** тавина (`lib/page-banners.ts` загвараар). Гэхдээ stock нь бизнестэй таарсан байх ёстой: түгээлт, агуулах, дэлгүүрийн тавиур, савласан бараа, ажлын баг. Код бичиж буй хүмүүс, ногоо жимс, сонин гэх мэт хамааралгүй зураг тавихгүй.
- Логоны навчин тэмдгийг бараан хэсэг болон хоосон төлөвт бүдэг чимэглэл болгон ашиглаж болно.
- Баннер дээрх текст уншигдахын тулд доороос `brand-night` градиент тавина (`PageBanner`-т байгаа).

## Лого

- `Wordmark` компонент (`components/site/wordmark.tsx`) хэвтээ логог inline SVG-ээр `currentColor`-оор зурдаг. Өнгийг `text-*`-ээр, хэмжээг `text-[..px]`-ээр (= логоны өндөр) өгнө.
- Нүүр болон Бидний тухай хуудсанд header hero зураг дээр тунгалаг, лого цагаан (`HERO_PATHS`). Бусад хуудсанд header цагаан дэвсгэртэй, лого хөх. Гүйлгэх үед доороо 1px шугам + зөөлөн `brand-night` сүүдэртэй болж, контент доогуур нь орж байгаа нь тод харагдана. Бараан дэвсгэр, footer дээр цагаан.
- Hero зургийн дээд 200px-д `brand-700` туяа байна (дээд 60px нь 85%, доошоо уусна). Ямар ч зураг оруулсан header-ийн цэс, хэл солих товч 4.5:1-ээс доош ялгаралтай болохгүйн тулд. Хэл солих товчны идэвхгүй хэл `white/85`.
- Гарын авлагын дагуу цагаан логог шууд зураг дээр тавихгүй. Зураг дээр хэрэгтэй бол гүн хөх градиент дэвсгэр дээр.
- Навчин тэмдэг дангаараа: favicon (`app/icon.svg`, `app/apple-icon.png`), бараан хэсгийн бүдэг чимэглэл.
- Эх файлууд: `public/brand/logo-horizontal.svg`, `logo-stacked.svg`, `logo-mark.svg` (`currentColor`).

## Хөдөлгөөн

- Одоогийн дүрэм хэвээр: `Reveal`, `ImageReveal`, `--ease-out`, 200–900ms, `prefers-reduced-motion`-ийг хүндэтгэнэ.
- Hover: карт өнгө солих эсвэл зураг 1.04 хүртэл томрох. Хоёуланг нь зэрэг хийхгүй.
- Зураг томрохдоо удаан, буцахдаа хурдан: `duration-250 group-hover:duration-500`. Хулганаа авмагц сайт шууд хариу өгнө.
- Дарж болох карт дарахад бага зэрэг жижгэрнэ: `active:scale-[0.98]` (бүтэн өргөнтэй том карт `0.99`), `duration-160 ease-out`.
- Зураг ачаалагдмагц гэнэт гарч ирэхгүй: `FadeInImage` нь 300ms-д бүдэг гаргана. `priority` зураг (хуудасны эхний том зураг) бүдгэрэхгүй, шууд харагдана.

## Layout давтагдахгүй байх

- Зүүн, баруун ээлжилдэг зураг+текст layout нэг хуудсанд **нэг л удаа**.
- Нэг төрлийн агуулга (брэнд, мэдээ) бүх хуудсанд **нэг ижил картаар** харагдана. Мэдээ ганц л онцгой тохиолдол: медиа хуудасны тайз ба тууз (`NewsSlide`, `NewsThumb`). Бүгд хайрцаггүй, ижил hover, ижил огноотой тул нэг гэр бүл.
- Брэндийн карт (`BrandLogoCard`) хаана ч ижил: Брэндүүд хуудсанд 4 / 3 / 2 багана, брэндийн дэлгэрэнгүйн «Бусад брэнд»-д 4 хүртэл.
