# Cosmo вэбсайтын дизайны дүрэм

Нийтийн сайтын (`src/components/site`, `src/app/(site)`) бүх шинэ ажил энэ дүрмийг дагана. Админ панел shadcn-ийн өөрийн загвартай тул хамаарахгүй.

## Энэ баримтыг хэрхэн өөрчлөх вэ

Энэ бол амьд баримт. Аль нэг хэсэгт шинэ загвар хүсвэл (жишээ нь өөр сайтын скриншот):
1. Хүсэлт энэ дүрэмтэй зөрчилдөх эсэхийг эхлээд шалгана.
2. Зөрчилдвөл юутай зөрчилдөж байгааг хэлээд, хоёр сонголт өгнө: дүрмийг дагасан хувилбар эсвэл дүрмийг өөрчлөх.
3. Шинэ загвар батлагдмагц **энэ баримтад дүрэм болгон нэмнэ**. Ингэснээр бусад хуудас ч түүнийг дагана.

## Чиглэл

**Логоноос эхэлсэн, итгэлтэй, цэвэрхэн, найрсаг корпорацийн сайт.**

Логоны үсгүүд бөөрөнхий, геометр хэлбэртэй. Навчин тэмдэг нь зөөлөн, амьд мэдрэмжтэй. Тиймээс сайт ч мөн хурц, хатуу биш, **зөөлөн булантай, нэг гүн хөх өнгөтэй** байна. Чимэглэл бага, зураг болон агуулга гол үүрэгтэй.

## Өнгө

Эх сурвалж нь брэндийн албан ёсны гарын авлага (`CosmoTrade BrandGuideline26.pdf`, 2026). Лого, өнгө, фонтын асуудлаар энэ баримт гарын авлагатай зөрчилдвөл **гарын авлага давамгайлна**.

Палитр: Deep Blue `#1B4D7F`, Soft Ivory `#F9FCF0`, Dusty Blue `#84ABCE`, Muted Gold `#FBC877`, Terracotta `#E9624C`. Гарын авлагын 60-30-10 дүрэм: 60% ivory суурь, 30% гүн хөх, 10% тодотгох өнгө. Вэбсайтад суурь нь цагаан (доор тайлбарласан).

Сайт голдуу **хөх болон саарал** өнгөтэй. Шүрэн болон шаргал нь зөвхөн маш цөөн тодотголд (жишээ нь «Шинэ» шошго, газрын зургийн цэг) хэрэглэгдэнэ. Товч, гарчиг, дэвсгэрт хэрэглэхгүй.

| Токен | Утга | Хэрэглээ |
|---|---|---|
| `brand` | `#1B4D7F` | Үндсэн товч, идэвхтэй цэс, icon, тоо |
| `brand-600` | `#17426C` | Товчны hover |
| `brand-700` | `#133659` | Цайвар дэвсгэр дээрх холбоос текст |
| `brand-400` | `#84ABCE` | Палитрын цайвар хөх: бараан дэвсгэр дээрх тодотгол |
| `brand-300` | `#B5CDE2` | Бараан дэвсгэр дээрх eyebrow |
| `brand-200` | `#D6E3EF` | Идэвхтэй/сонгогдсон дэвсгэр |
| `brand-100` | `#EBF1F7` | Hover дэвсгэр, картын цайвар дэвсгэр |
| `brand-night` | `#0B1F33` | Бараан хэсэг (газрын зураг, footer, зарчмууд) |
| `coral` / `amber` | `#E9624C` / `#FBC877` | Ховор тодотгол |
| `white` | `#FFFFFF` | Хуудасны дэвсгэр, header, гар утасны цэс |
| `ivory` | `#F9FCF0` | Soft Ivory. Хуудасны дэвсгэрт биш, хэрэгтэй бол бүтэн өргөнтэй тууз болгон |
| `paper` | `#F5F6F8` | Цайвар саарал карт (бүтээгдэхүүний карт), hero-гийн дууны товч, каталогийн хуудас |

- Хуудасны дэвсгэр нь **цагаан** (`bg-white`). Ivory-г бүх хуудсанд туршсан ч дэлгэц дээр ногоовтор харагдаж, хөхөвтөр саарал карт, цагаан header-тэй зөрчилдсөн. Гарын авлага өөрөө цагаан хуудсан дээр хийгдсэн, цагаан нь логонд зөвшөөрөгдсөн дэвсгэр. Саарал хуудасны дэвсгэр ч бүдэг, «бохир цагаан» мэт харагддаг тул хэрэглэхгүй. Бараан хэсэг (`brand-night`) хуудас бүрт **хамгийн ихдээ нэг** удаа, footer-ээс гадна.
- Hex утгыг компонентод шууд бичихгүй, зөвхөн токен ашиглана.

## Булан (radius)

| Юу | Булан |
|---|---|
| Карт, зураг, панел, ангиллын карт | `rounded-card` (20px) |
| Товч, input, select, шүүлтүүр, жижиг шошго | `rounded-control` (10px) |
| Жижиг зураг (лого хайрцаг, thumbnail) | 12px |
| Бүтэн өргөнтэй баннер, бараан хэсэг, header, footer | 0, дэлгэцийн ирмэгт наалдана |

Хурц (0px) булантай карт, товч цаашид хэрэглэхгүй.

## Хүрээ, тусгаарлалт

- **Картыг шугамаар биш, дэвсгэрээр** ялгана (`bg-surface` эсвэл `bg-paper`). Картын эргэн тойронд border тавихгүй.
- Цагаан дэвсгэртэй зураг (бүтээгдэхүүн, брэндийн лого) саарал карт эсвэл өнгөт тууз дээр цагаан дөрвөлжин болж харагдахгүйн тулд `mix-blend-multiply` хэрэглэнэ.
- Мэдээний зургийн дотор талд `ink`-ийн 8%-тай 1px сүүдэр (`NewsCover`) байна. Энэ нь border биш: цайвар дэвсгэр дээр цайвар зургийн ирмэг уусахгүй байлгана.
- Шугам (`border-rule`, 1px) зөвхөн жагсаалтын мөр, хүснэгт, footer-ийн доод мөрөнд хэрэглэнэ.
- Section-уудыг шугамаар биш, **зай болон дэвсгэрийн өнгөөр** тусгаарлана.

## Үсэг

- Фонт (брэндийн гарын авлага): гарчиг, тоо, eyebrow нь **IBM Plex Sans** (`font-display`). Үндсэн текст, товч, цэс нь **Roboto** (`font-sans`). Хоёулаа кирилл Ө Ү бүрэн. Хятадад Noto Sans SC.
- `type-*` utility болон h1–h4 элемент IBM Plex Sans-ийг автоматаар авна. Гарчиг биш элементэд гарчгийн фонт хэрэгтэй бол `font-display` нэмнэ.
- Гарчгийн үсгийн зай `-0.02em`-ээс илүү шахахгүй. IBM Plex Sans өөрөө нягт фонт.
- Хэмжээ (`globals.css`). Шинэ хэмжээ зохиохгүй, эдгээрээс сонгоно. **Хуудасны гарчиг үргэлж хамгийн том.**

| Токен | Компьютер / гар утас | Хэрэглээ |
|---|---|---|
| `type-display` | 40 / 32px | Хуудасны h1: баннер, брэндийн нэр, мэдээний гарчиг, Холбоо барих |
| `type-h2` | 36 / 28px | Section-ийн гарчиг |
| `type-h3` | 28 / 22px | Картын болон дэд гарчиг |
| `type-h4` | 22 / 18px | Жижиг картын гарчиг |
| `type-stat` | 48 / 36px | Зөвхөн тоо |
- `eyebrow` (жижиг том үсгэн шошго) хуудас бүрт **3 section тутамд хамгийн ихдээ 1**.
- Дугаарласан шошго (01, 02…) хэрэглэхгүй.

## Зай

- Section хоорондын зай: `pt-20 md:pt-32` (өнгөт дэвсгэртэй хэсэгт `mt-20 md:mt-32`). Өөр утга (28, 36, 40) хэрэглэхгүй.

## Icon

- Тоон үзүүлэлт гэх мэт **брэндийн дүрслэлийн icon**: гарын авлагын өөрийн icon багц (`Brand icon set.ai`), `components/site/brand-icons.tsx` (хөх `fill-brand` + terracotta `fill-coral`, хоёр өнгөтэй). Шинэ icon хэрэгтэй бол AI файлаас ижил аргаар нэмнэ.
- Бусад UI icon (сум, chevron, цэс, хаах, дуу): **lucide-react**. Өөр сан холихгүй.
- Зураасны зузаан: дүрслэлийн icon (картан дээрх, тоон үзүүлэлтийн, мэдээллийн мөрийн) **`strokeWidth={1.5}`**. Сум, chevron зэрэг жижиг UI icon анхдагч утгаараа (2).
- Хэмжээ: 20px (мөр доторх), 24px (жагсаалт), 48px (карт).
- Icon-д дэвсгэр хэрэгтэй бол: `rounded-control` + цайвар дэвсгэр (`bg-brand-100`, бараан дээр `bg-white/10`). Хүрээтэй icon хайрцаг хэрэглэхгүй.

## Нүүр хуудасны hero carousel

- `components/site/home/hero-carousel.tsx`. Header-ийн **доор**, бүтэн өргөнтэй. Өндөр нь `HERO_HEIGHT_CLASS` (`hero-size.ts`): 360 / 432 (sm) / 480 (xl) / 584px (1440px+). Слайдгүй үеийн `HeroFallback` ч ижил өндөртэй.
- Слайд 4 секунд тутамд хажуу тийш гулсаж солигдоно (600ms, `cubic-bezier(0.32, 0.72, 0, 1)`). Төгсгөлгүй давтагдана: сүүлийнхээс эхнийх рүү буцаж гүйхгүй.
- Хулгана, хуруугаар чирж солино. 50px-ээс их чирэх эсвэл хурдан шидэхэд солигдоно, бага бол буцаж байрандаа орно. Чирж байх үед autoplay зогсоно.
- Зүүн, баруун сум: хүрээгүй, `bg-brand-night/25` бөөрөнхий дэвсгэр, blur. Цайвар зураг дээр ч харагдана.
- Indicator: зурагны доод төвд жижиг дугуй цэгүүд (12px, 1.5px цагаан хүрээ, идэвхтэй нь цагаанаар дүүрнэ, бага зэрэг сүүдэртэй). Autoplay нь timer-ээр (`SLIDE_DURATION_MS`), чирж байх эсвэл гулсаж байх үед зогсоно.
- Зурган дээр зөвхөн сум, цэгүүд, видеоны дууны товч.

## Нүүр хуудасны тоон үзүүлэлт

- `components/site/home/key-stats.tsx`. Hero-гийн шууд доор бүтэн өргөнтэй **цайвар хөх тууз** (`bg-brand-100`, Dusty Blue-гийн цайвар өнгө), өндөр нь ойролцоогоор 160px. Картгүй.
- 4 зүйл нэг мөрөнд (утсан дээр 2×2). Зүүн талд гарын авлагын icon (жинхэнэ өнгөөрөө), баруун талд нь жижиг том үсэгтэй шошго (`ink-2`), доор нь гүн хөх тод тоо (28/22px, 0-ээс тоологдоно).
- Дарагддаггүй тул hover өнгө солихгүй.
- Доор нь «Бидний тухай» хэсэг (`about-intro-section.tsx`): зүүн талд гарчиг, баруун талд тайлбар + товч.

## Нүүр хуудасны «Брэндүүд» (Bento)

- `components/site/home/brand-bento.tsx`. Админ → Нүүр хуудас → «Онцлох брэндүүд»-д сонгосон 5 хүртэл брэнд (`Brand.featuredOrder`). Сонгоогүй бол брэндийн ерөнхий дарааллаар эхний 5. 1-рх нь том нүд, 2-рх нь өргөн, бусад нь жижиг. Брэнд цөөн бол нүдний хуваарь өөрчлөгдөж, хоосон нүд хэзээ ч үлдэхгүй (`LAYOUTS`).
- Нүд бүр брэндийн **нүүр зураг**, доороос `brand-night` градиент, цагаан нэр + ангилал, лого 10px бөөрөнхий цагаан хайрцагт. Hover дээр зураг 1.05, баруун дээд буланд сум.
- Нүүр зураггүй брэнд: `brand` → `brand-night` градиент, цагаан дугуйн дотор лого, бүдэг навчин тэмдэг.
- Брэнд бүрийг жагсаах ажлыг «Манай харилцагчид» тууз хийдэг тул энд шүүлтүүр, carousel хэрэглэхгүй.

## Нүүр хуудасны «Үнэт зүйл» (Accordion)

- `components/site/home/values-accordion.tsx`. 4 зургийн тууз (460px, утсан дээр дээрээс доош 620px). Хулганаар очих, дарах эсвэл Tab-аар ороход тэр тууз өргөсөж (`grow-[3.2]`) тайлбар нь гарна. Бусад нь бага зэрэг бүдэг.
- Зураг: Админ → Бидний тухай → Үнэт зүйлсийн зураг. Байхгүй бол `VALUE_IMAGE_PLACEHOLDERS`. Хэвтээ зураг хаалттай үедээ голоороо тайрагдана.
- Текст хаалттай үед ч DOM-д байгаа тул дэлгэц уншигч бүгдийг уншина.

## Брэндийн лого гүйдэг хэсэг

- Нүүр хуудсанд «Мэдээлэл»-ийн дээр. Тусдаа дэвсгэргүй энгийн section (`pt-20 md:pt-32`). Лого нь бүтэн өргөнөөр гүйнэ. Гарчиг нь `type-h2` («Манай харилцагчид», `home.partnersTitle`), доогуураа 3px градиент шугамтай (`brand` → `brand-400` → `rule`).
- Лого хүрээ, дэвсгэргүй, өнгөөрөө. 8 ба түүнээс олон брэндтэй үед 2 эгнээ эсрэг чиглэлд, цөөн үед 1 эгнээ.
- Контейнер: `site-container` (90rem). Бүтэн өргөнтэй зүйлс (баннер, гүйдэг жагсаалт) л үүнээс гарна.

## Мэдээ

Бүх мэдээний карт **хайрцаггүй**: зураг өөрөө карт, текст шууд хуудасны дэвсгэр дээр.

| Компонент | Хаана | Хэлбэр |
|---|---|---|
| `NewsCard` | Медиа хуудасны жагсаалт, «Бусад мэдээ», нүүрний 2 мэдээтэй үе | 16:10 зураг, огноо, `type-h4` гарчиг, 2 мөр хураангуй |
| `NewsCard isLarge` | Нүүрний том мэдээ | `type-h3` гарчиг, 3 мөр хураангуй |
| `NewsRow` | Нүүрний баруун талын жагсаалт | 4:3 жижиг зураг (12px булан) + огноо + 18px гарчиг, мөр хооронд `divide-rule` |
| `FeaturedNews` | Медиа хуудасны эхний мэдээ, нүүрт ганц мэдээтэй үед | Зураг 7 багана + текст 5 багана |

- **Нүүр хуудасны «Мэдээлэл»** (`latest-news-section.tsx`) мэдээний тоогоор хэлбэрээ сольж, хоосон багана хэзээ ч үлдээхгүй: 1 бол `FeaturedNews`, 2 бол том карт + `NewsCard`, 3–4 бол том карт + `NewsRow` жагсаалт.
- Огноо богино: «2026.10.20» (`NewsDate isShort`). Мэдээний дэлгэрэнгүй хуудсанд урт хэлбэрээр.
- «Мэдээ» шошго тавихгүй (хэсгийн гарчгийг давтдаг). Видео мэдээнд «Видео» шошго болон зургийн зүүн доод буланд 12px зайтай, `rounded-control` тоглуулах тэмдэг.
- Зураг бүр `NewsCover`-оор: саарал дэвсгэр дээр бүдэг гарч ирнэ (`FadeInImage`), hover дээр томорно, 1px дотор сүүдэртэй.

## Зураг

- Зорилго нь **компанийн өөрийн зураг**: агуулах, машин, хамт олон, бүтээгдэхүүн, брэндийн албан ёсны зураг. Админаас солигдоно.
- Зураг хараахан байхгүй бол текстээр орлуулахгүй, хоосон саарал дөрвөлжин ч үлдээхгүй. **Түр stock зураг** тавина (`lib/page-banners.ts` загвараар). Гэхдээ stock нь бизнестэй таарсан байх ёстой: түгээлт, агуулах, дэлгүүрийн тавиур, савласан бараа, ажлын баг. Код бичиж буй хүмүүс, ногоо жимс, сонин гэх мэт хамааралгүй зураг тавихгүй.
- Логоны навчин тэмдгийг бараан хэсэг болон хоосон төлөвт бүдэг чимэглэл болгон ашиглаж болно.
- Баннер дээрх текст уншигдахын тулд доороос `brand-night` градиент тавина (`PageBanner`-т байгаа).

## Лого

- `Wordmark` компонент (`components/site/wordmark.tsx`) хэвтээ логог inline SVG-ээр `currentColor`-оор зурдаг. Өнгийг `text-*`-ээр, хэмжээг `text-[..px]`-ээр (= логоны өндөр) өгнө.
- Header-т үргэлж хөх. Header цагаан дэвсгэртэй, зураг дээр тунгалаг болдоггүй. Гүйлгэх үед доороо 1px шугам + зөөлөн `brand-night` сүүдэртэй болж, контент доогуур нь орж байгаа нь тод харагдана. Бараан дэвсгэр, footer дээр цагаан.
- Гарын авлагын дагуу цагаан логог шууд зураг дээр тавихгүй. Зураг дээр хэрэгтэй бол гүн хөх градиент дэвсгэр дээр.
- Навчин тэмдэг дангаараа: favicon (`app/icon.svg`, `app/apple-icon.png`), бараан хэсгийн бүдэг чимэглэл.
- Эх файлууд: `public/brand/logo-horizontal.svg`, `logo-stacked.svg`, `logo-mark.svg` (`currentColor`).

## Хөдөлгөөн

- Одоогийн дүрэм хэвээр: `Reveal`, `ImageReveal`, `--ease-out`, 200–900ms, `prefers-reduced-motion`-ийг хүндэтгэнэ.
- Hover: карт өнгө солих эсвэл зураг 1.04 хүртэл томрох. Хоёуланг нь зэрэг хийхгүй.
- Зураг томрохдоо удаан, буцахдаа хурдан: `duration-250 group-hover:duration-500`. Хулганаа авмагц сайт шууд хариу өгнө.
- Дарж болох карт дарахад бага зэрэг жижгэрнэ: `active:scale-[0.98]` (бүтэн өргөнтэй том карт `0.99`), `duration-160 ease-out`.
- Зураг ачаалагдмагц гэнэт гарч ирэхгүй: `FadeInImage` нь 300ms-д бүдэг гаргана.

## Layout давтагдахгүй байх

- Зүүн, баруун ээлжилдэг зураг+текст layout нэг хуудсанд **нэг л удаа**.
- Нэг төрлийн агуулга (брэнд, мэдээ) бүх хуудсанд **нэг ижил картаар** харагдана. Мэдээ ганц л онцгой тохиолдол: нүүр хуудсанд том карт + `NewsRow` жагсаалт. Бүгд хайрцаггүй, ижил hover, ижил огноотой тул нэг гэр бүл.
